No cookies.

This site doesn't use cookies and doesn't save anything in your browser. No analytics, no advertising, no tracking.

Fonts

The front page and the 404 page load their typefaces (Inter and JetBrains Mono) from Google Fonts. To send them, Google receives your IP address and basic browser details. This page loads nothing from anyone else.

Hosting

The site is hosted on GitHub Pages. As with any host, GitHub may log technical details such as your IP address when a page is served.

Links

LinkedIn and GitHub open their own sites, which have their own policies.

If this changes

If I ever add analytics or anything else that uses cookies, I'll ask first and update this page. Questions? Message me on LinkedIn (opens in a new tab).
